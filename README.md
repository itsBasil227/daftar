# دفتر — Daftar Notes

برنامج ملاحظات بخط اليد يشتغل على أي تابلت (iPad، سامسونج، هواوي، ويندوز):
قلم بالضغط، مساحة لا نهائية، فتح PDF والكتابة عليه، شريط مراجعة للدراسة، عربي وإنجليزي.
كل البيانات محفوظة على الجهاز نفسه، ويشتغل بدون إنترنت بعد أول فتح.

## المزايا
- **كتابة ناعمة:** تنعيم 1€ ومنحنيات ما تنحرف، ونفس شكل الخط وقت الكتابة وبعد رفع القلم.
- **تسجيل صوت مربوط بالكتابة:** سجّل المحاضرة وأنت تكتب، وبعدين بأداة التحريك ✋ اضغط على أي كلمة تسمع اللي انقال وقتها. الكتابة اللي جات بعد اللحظة الحالية تظهر باهتة.
- **مراجعة البطاقات:** أشرطة المراجعة تصير بطاقات بنظام التكرار المتباعد (ما عرفتها / عرفتها / سهلة)، والبرنامج يرجع لك البطاقة في وقتها.
- **علامات:** احفظ أي مكان في الدفتر وارجع له بضغطة.
- **مؤقت مذاكرة:** تركيز 25 أو 45 أو 60 دقيقة، وبعدها استراحة تلقائية.
- **ملء الشاشة** للعرض والشرح.
- **نسخ ولصق بين الدفاتر:** Ctrl+C و Ctrl+V، أو زر النسخ في شريط التحديد ثم «لصق» من قائمة الإدراج.
- **مكتبة أذكى:** تثبيت الدفاتر في الأعلى، ترتيب بالأحدث أو بالاسم، والبحث يشمل النصوص المكتوبة داخل الدفاتر.
- **أوراق جديدة:** بهامش، متساوية (isometric)، نوتة موسيقية، إضافة للمسطّرة والمربعات والنقاط.

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | البرنامج كامل |
| `manifest.json` | يخلي البرنامج يتثبت كتطبيق (الاسم والأيقونة) |
| `sw.js` | يشغّل البرنامج بدون إنترنت |
| `icon-*.png`, `apple-touch-icon.png` | الأيقونات |

## النشر على GitHub Pages
1. ادخل github.com وسوّ مستودع جديد (New repository)، مثلاً باسم `daftar`، واختره **Public**.
2. اضغط **Add file → Upload files** وارفع كل الملفات اللي في هذا المجلد، ثم **Commit changes**.
3. روح **Settings → Pages**، وتحت **Build and deployment** اختر:
   - Source: **Deploy from a branch**
   - Branch: **main** والمجلد **/(root)** ثم **Save**.
4. بعد دقيقة أو دقيقتين يطلع لك الرابط: `https://اسم-حسابك.github.io/daftar/`

## التثبيت على الجهاز
- **iPad / iPhone:** افتح الرابط في Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.
- **أندرويد (سامسونج وغيره):** افتح الرابط في Chrome ← القائمة ⋮ ← **تثبيت التطبيق**.
- **ويندوز:** افتحه في Edge أو Chrome ← أيقونة التثبيت في شريط العنوان.

## تحديث البرنامج
لما تعدّل `index.html` ارفعه من جديد، وغيّر رقم النسخة في أول سطر من `sw.js`
(مثلاً `daftar-v9` إلى `daftar-v10`) عشان الأجهزة تاخذ التحديث.

> ملاحظة: الدفاتر محفوظة في متصفح كل جهاز. لنقلها بين الأجهزة استخدم «حفظ نسخة احتياطية» ثم «استيراد».
